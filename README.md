# Gamble With Your Friends - Traducción al Español

Traducción fanmade al español para Gamble With Your Friends.

## Características
- Traducción completa de menús e interfaz de usuario
- Adaptación cultural al español
- Compatible con XUnity.AutoTranslator
- Optimizada para Thunderstore

## Requisitos
- BepInEx
- XUnity.AutoTranslator (versión 5.6.1 o superior)

## Instalación
Instalar mediante Thunderstore Mod Manager o r2modman:
1. Busca "Spanish Translation" en tu gestor de mods
2. Descarga e instala
3. ¡Disfruta del juego en español!

## Notas Importantes
- **Sobre las tildes:** La traducción en el juego NO contiene tildes acentuadas (á, é, í, ó, ú, ñ) debido a limitaciones de fuentes y compatibilidad del juego. Esto no afecta la legibilidad, pero es importante saberlo si editas los archivos.
- Algunos textos pueden cambiar según versiones futuras del juego.
- Esta traducción aún no está terminada al 100%, pero cubre la mayoría del contenido principal.
